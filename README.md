# cootshk.dev

Welcome to a website of all time:tm:.

Hosted on GitHub pages, because why not?

_Most_ something.cootshk.dev/ links get redirected to cootshk.dev/something.
the [404 page](404.html) is abused for [quick redirects](redirects.json), so feel free to send a PR if you have more to add.

Also sometimes I throw vibe coded tools up here because I need them hosted; don't expect support on any of them.

`scripts/dev.sh` will start the local server with the proxy. (Or, just `python3 -m http.server` if you don't need it.)

### Contributing

PRs welcome, run `cp -r git/hooks .git/hooks` to install the pre-commit hook.
